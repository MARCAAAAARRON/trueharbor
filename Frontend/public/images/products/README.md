# TrueHarbor Product Photography

This directory is ready for real product photos. You can add product images in two convenient ways:

### 1. Cloudinary Admin Quarterdeck (Recommended)
Log in at `http://localhost:5173/admin` with `admin@trueharbor.test` / `password`, go to **Provisions & Stock**, and click **Edit** or **Manage Gallery** on any product to upload directly via Cloudinary CDN.

### 2. Direct File Drop
You can also drop image files directly into this directory (`Frontend/public/images/products/`) named by product slug. Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`.
